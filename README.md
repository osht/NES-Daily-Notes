# NES Daily Note Writer

Standalone responsive HTML app for drafting daily documentation notes in a browser.

## Upload
1. Create a repository in your company-approved GitHub account or organization.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root.
3. Configure GitHub Pages under **Settings → Pages** if your plan and company policy allow it.

## Important hosting note
A private repository does not automatically make a GitHub Pages site private. GitHub Pages private-site access requires GitHub Enterprise Cloud. Verify site visibility and your organization's requirements before publishing.
